Project 03 · Trend following

The simplest strategy, tested honestly.

The rule: go long when the 50-day average crosses above the 200-day (golden cross) and go flat on a death cross. What matters is the test. The signal is executed the next session, every trade pays fees and slippage, and the result is compared with simply holding the asset. A daily GitHub Actions job also e-mails me whenever a cross happens on my watchlist.

Alerts

Get notified on every golden or death cross.

Every weekday at 21:30 UTC, after the US close, a GitHub Actions job runs quant/alert.py on GitHub's servers, so it works even when the laptop is off. If SMA 50 crossed SMA 200 on the last session for any ticker on the watchlist, it sends an e-mail and a push notification to the phone.

01

Gmail App Password

Google Account → Security → 2-Step Verification → App passwords. Create one called “SMA alerts” and copy the 16 characters.

02

GitHub secrets

Repo → Settings → Secrets → Actions. Add SMTP_USER, SMTP_PASSWORD, ALERT_TO, plus a variable WATCHLIST such as SPY,QQQ,AAPL.

03

Phone push (optional)

Install the free ntfy app, subscribe to a random topic name, and add it as the NTFY_TOPIC secret.

04

Test it

Actions → “SMA crossover alert” → Run workflow → mode test. A sample e-mail arrives within a minute.

Or run it locally from Spyder / terminal

export SMTP_HOST=smtp.gmail.com SMTP_PORT=465
export SMTP_USER=you@gmail.com SMTP_PASSWORD=xxxxxxxxxxxxxxxx
export WATCHLIST=SPY,QQQ,AAPL NTFY_TOPIC=my-secret-topic
python -m quant.alert --test      # send a test now
python -m quant.alert             # daily check: notifies only on a new cross

Conclusions

—

  • One-day delay: executing at the signal day's close uses information you did not have. The table shows how much it inflates the result.
  • Costs: the 50/200 rule trades rarely, so costs barely matter here. Shorten the averages to 10/30 and watch them grow.
  • Market regime: trend following loses in choppy years (whipsaws) and earns its keep in long bear markets such as 2008 and 2022, mostly by cutting drawdowns rather than adding return.
